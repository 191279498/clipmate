打开豆瓣条目、IMDb、YouTube、B 站、小红书、抖音……点一下，采媒灵把散落在页面上的信息（片名、导演、ISBN、作者、播放量、发布时间）整理成一张卡片，再按你选的格式复制走。

它不是「一键摘抄全文」，而是**按内容类型提取字段**：同一套输出字段在 23 个站点上是统一的，所以从豆瓣和从 IMDb 拿到的结果可以并排放进同一张表。

## 它做什么

- **认站点，也认内容类型** —— 自动判断当前页是影视、书籍、游戏、社交还是人物档案，用对应的提取器取字段，不用你手动选。
- **结构化，不是一坨文本** —— 输出是「字段: 值」的结构化结果，可直接粘进 Notion、Markdown 表、Excel。
- **社交站点逐帖处理** —— 信息流页面上给每条帖子挂一个按钮，只提取你要的那一条，不用整页抓。
- **设置归位** —— 全局默认、按站点覆盖、字段顺序、输出格式都在一个设置页里；popup 只改当前这个站。

## 支持的站点

| 分类 | 站点 |
| --- | --- |
| 影视 | 豆瓣电影 · TMDB · IMDb · Bangumi |
| 书籍 | 豆瓣读书 · 起点中文网 · 番茄小说 · 17K小说网 · Goodreads |
| 游戏 | 豆瓣游戏 · Steam · Metacritic · 小黑盒 · MobyGames |
| 社交媒体 | B站 · 抖音 · 快手 · 小红书 · 微博 · X · Instagram · YouTube · TikTok |
| 人物档案 | 上述站点中的作者 / 演员 / UP 主主页 |

社交站点支持**视频、图文、信息流**三种页面形态；人物主页会额外提取简介与作品列表。

## 安装

本扩展未上架应用商店，用开发者模式加载：

1. 下载本仓库（`Code` → `Download ZIP`，或 `git clone`）。
2. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`）。
3. 打开右下角 / 右上角的 **开发者模式**。
4. 点 **加载解压缩的扩展**，选择仓库里的 `ClipMate_chrome` 文件夹。
5. 打开任意受支持的站点，点工具栏上的采媒灵图标。

> 不需要构建、不需要 npm install —— 仓库里的 `ClipMate_chrome/` 就是可直接加载的成品目录。

## 用法

打开一个条目页（比如豆瓣读书的某本书），会有两种方式触发：

- 页面右下角/信息流里的 **提取信息** 按钮；
- 工具栏图标 → popup 里改本站开关，或在设置页里打开「自动提取」。

提取完成后按设置的格式（Notion / Markdown / 纯文本）复制。想连续采集，打开 **自动提取 + 自动复制**，翻页即取。

## 设置

设置页分五个页签：

| 页签 | 管什么 |
| --- | --- |
| 通用 | 自动提取与等待时间、自动复制与格式、按钮显示、主题、缓存 |
| 网站 | 23 个站点逐个覆盖全局设置（不填 = 跟随全局） |
| 字段 | 每一类内容的字段顺序，拖动排序 |
| 数据 | 缓存占用与清除、配置导出 / 导入、分区重置 |
| 关于 | 版本、支持的站点、常见问题 |

popup 只做一件事：**改当前这个站**。碰哪个开关就按本站生效，底部一行「恢复默认」可以退回全局。

## 隐私

- 所有提取都在**本地页面内**完成，扩展不发任何网络请求、不上报数据、不需要登录。
- 只有你主动复制或下载时，数据才会离开浏览器（进剪贴板 / 进下载目录）。
- 权限只申请「读取当前页面」与「本地存储」，没有远程代码，`manifest.json` 里可以直接核对。

## 目录结构

```
ClipMate_chrome/           可直接加载的扩展目录
├── manifest.json
├── icons/
└── src/
    ├── background/        服务层：配置读写、缓存、消息路由
    ├── content/           内容脚本
    │   ├── content-main.js        入口、浮窗、按钮挂载
    │   ├── extractors/            23 个站点的提取器（每个站一个文件）
    │   ├── utils/                 字段映射、数据清洗、格式输出
    │   └── ui/                    浮窗与按钮样式
    ├── options/           设置页（五页签）
    ├── popup/             工具栏浮窗
    └── shared/            站点清单、缓存、配置结构、功能开关
tests/                     单元测试与快照测试（Node，无需浏览器）
设计系统/                  设计系统说明页与吉祥物素材
```

## 开发与测试

提取器的写法是「一个站点一个文件，实现 `extractAllFields()`」，注册到站点清单即可。改代码前建议先跑一遍测试：

```bash
cd tests
node preflight.js          # 发布前自检：结构、版本、快照、契约测试
node snapshot.js           # 19 个真实页面样本的字段级快照比对
node settings-page.test.js # 设置页契约测试
```

测试用 Node + jsdom 跑，不需要启动浏览器。`tests/fixtures/` 里的真实页面存档**未随仓库分发**（体积与第三方内容授权原因），需要自行抓取后才能跑快照测试，格式见 `tests/README.md`。
